# Gravity Lab

Физическая головоломка от первого лица в духе тестовых камер: игрок с гравитационной пушкой проходит
20 камер, ловит кубы, бросает их, переворачивает им гравитацию, замораживает их в воздухе, ведёт лазеры
через зеркала и ездит на платформах и в восходящих потоках. Для каждой камеры есть таймер, ранг (S/A/B/C)
и рекорд. Сцену целиком строит код: процедурная геометрия, шейдеры, текстуры, UI и звук.

## Как открыть

1. Unity **2022.3.30f1** или **Unity 6 (6000.0)**, встроенный рендер-пайплайн (Built-in).
2. Откройте папку `GravityLab` через Unity Hub. После импорта редакторный скрипт сам создаст
   `Assets/Scenes/Main.unity` с одним объектом `Bootstrap`, добавит сцену в Build Settings и выставит
   настройки для ПК: FullScreenWindow, окно 1920×1080, изменяемый размер окна.
   Если сцена не появилась, выполните **GravityLab → Rebuild Main Scene**.
3. Нажмите Play. Лучше всего игра выглядит в Game view с соотношением 16:9 или 16:10.

Работают оба бэкенда ввода: старый Input Manager, новый Input System (пакет 1.7.0) и режим «Both».

## Механики

- **Гравипушка** (`GravityGun`): объект удерживается физически. Критически задемпфированная пружина
  тянет его к точке перед камерой, поэтому он сталкивается с миром и выпадает из захвата, если отстал больше
  чем на 2 м или пропала прямая видимость. Через стекло можно прицелиться, но протащить объект нельзя.
  Объект в руках поворачивается вместе с игроком (с шагом 90° от угла, под которым его взяли).
- **Своя гравитация** (`PhysicsProp`): у каждого куба собственное направление гравитации (вниз или вверх).
  Перевёрнутые кубы прилипают к потолку, поэтому срабатывают потолочные плиты и потолочные конвейеры.
- **Заморозка**: куб на 5 секунд становится кинематическим, и на него можно встать. В конце мигает.
- **Нажимные плиты**: считают массу. Обычная плита требует 20 кг, тяжёлая (оранжевая) 50 кг.
  Тип `Any` учитывает игрока, тип `PropsOnly` реагирует только на кубы. Плиту можно поставить и на потолок.
- **Лазеры**: луч трассируется серией рейкастов. Неподвижные зеркала его отражают, куб-отражатель
  переизлучает луч через линзу (пока куб в руках, он луч просто блокирует). Приёмники бывают обычные
  и защёлкивающиеся. Стекло и игрок лучу не мешают.
- **Энергетические поля** растворяют любые кубы, в том числе те, что в руках. Куб пересобирается
  у своего раздатчика. Поле можно инвертировать, то есть выключать сигналом.
- **Конвейеры** (на полу и на потолке), **вентиляторы** (поднимают лёгкие кубы и игрока, но не тяжёлые кубы
  и не игрока с тяжёлым кубом в руках), **движущиеся платформы** (везут игрока и кубы), **двери**.
- **Провода-индикаторы** на полу ведут от источника сигнала к элементу: синий цвет — нет сигнала,
  оранжевый — есть.
- **Рассказчик** (OVERSEER) объясняет механики субтитрами: вступление в начале камеры и реплики в триггер-зонах.

## Архитектура

```
Assets/
  Editor/GravityLabSceneSetup.cs      автосоздание сцены и настройки Player для ПК
  Resources/Fonts                     LilitaOne, Fredoka (OFL)
  Resources/Shaders                   Lab, Glass, Unlit, Field, Particle (Built-in, CG)
  Scripts/
    Core/      Bootstrap (строит всё), GameManager (поток игры), GameInput (обёртка ввода),
               SaveSystem/SaveData (PlayerPrefs + JsonUtility), DisplaySettings, Layers, Palette, Rank, Tweener
    Player/    PlayerController: CharacterController, плавный разгон, coyote time, буфер прыжка,
               присед с проверкой потолка, покачивание головы, шаги, перенос платформой
    Gadgets/   GravityGun, GunViewModel (модель пушки из примитивов: покачивание, отдача, светящееся ядро)
    Puzzle/    PhysicsProp, PressurePlate, Door, LaserEmitter/Receiver/Mirror, ConveyorBelt, Fan,
               EnergyField, MovingPlatform, ExitElevator, NarratorZone, SignalWire, SignalSource (сигналы через И)
    Chambers/  ChamberBuilder (модульный кит), ChamberLibrary (20 камер), Chamber (рантайм-корень)
    Rendering/ MatLib, ProcTex (текстуры кубов, конвейера, слизи), FxManager (частицы), CameraShake, MenuCamera
    Audio/     AudioManager (пул голосов, музыка, гул удержания), SynthClips (синтез звука)
    UI/        UIManager, экраны (меню, выбор камеры, HUD, пауза, настройки, результат), виджеты, SDF-спрайты
```

- **Сигналы.** `SignalSource` (плита, приёмник) отдаёт `IsActive`. Потребитель (дверь, вентилятор,
  конвейер, платформа, поле) включается, когда активны все его входы.
- **Зоны** опрашиваются через `Physics.OverlapBoxNonAlloc` и через проверку точки в ориентированном боксе,
  без триггеров. Поведение не зависит от того, как CharacterController обрабатывает триггеры.
- **Слои** 8–11 (Props, Player, Held, Glass) используются без TagManager. Объект в руках не сталкивается
  с игроком.
- **Шейдер Lab**: half-lambert с подкрашенной тенью, мягкие тени (AutoLight), SH-эмбиент,
  процедурная сетка панелей в мировых координатах, фейковые отражения через френель (градиент окружения
  и блик потолочной лампы), а также glow, stasis и dissolve через MaterialPropertyBlock. Для растворения
  написан собственный ShadowCaster.
- **Glass** — френелевская прозрачность с бликами. **Field** — аддитивная анимированная завеса.

## Формат камер и как добавить новую

Камера — это `ChamberDef(name, parTime, introLines, build)` в `ChamberLibrary`. Скрипт сборки вызывает
методы кита (единица — метр, Y вверх):

```csharp
list.Add(new ChamberDef("My Test", 30f, new[] { "Реплика рассказчика." }, b =>
{
    Opening entry = Opening.Door(Side.South, 6f), exit = Opening.Door(Side.North, 6f);
    b.Room(0f, 0f, 12f, 14f, 6f, entry, exit);           // пол, стены с проёмами, потолок, лампы
    PressurePlate plate = b.Plate(P(8f, 0f, 7f));          // плита для кубов
    b.Cube(P(3f, 0f, 5f));                                  // куб с раздатчиком
    b.Entry(entry);                                         // лифт прибытия (точка спавна)
    b.Exit(exit, plate);                                    // лифт выхода, дверь открывается от плиты
}));
```

Методы кита: `Shell/Room`, `Floor`, `Block`, `Goo`, `WallX/WallZ` с `Gap`, `GlassX/GlassZ`, `Catwalk`,
`Cube`, `Plate/CeilingPlate`, `Emitter`, `Receiver`, `Mirror`, `Conveyor`, `Fan`, `Platform`, `Field`,
`InnerDoor`, `Say`. Провода прокладываются автоматически (`AutoWires`). Над каждой камерой в комментарии
описано задуманное решение. Ранг: S — время не больше par, A — до 1.5×par, B — до 2.2×par, иначе C.
Следующая камера открывается после прохождения текущей.

## Что демонстрирует проект

- Физический геймплей: пружинное удержание объекта, своя гравитация у каждого объекта, кинематическая
  заморозка, зоны-силы, переносящие платформы, лазер с отражениями на рейкастах.
- Data-driven дизайн уровней через модульный кит. 20 камер с кривой сложности, где механики сначала
  вводятся по одной, а потом комбинируются.
- Полностью процедурный контент: геометрия, шейдеры Built-in (CG), текстуры, SDF-спрайты UI,
  синтезированные SFX и музыка.
- Законченный ПК-продукт: главное меню, выбор камер, пауза, настройки (громкость, чувствительность,
  инверсия, FOV, покачивание головы, полноэкранный режим, разрешение, качество, VSync), экраны результата
  и провала, сохранения, захват курсора.
- Совместимость: Unity 2022.3 и Unity 6, оба бэкенда ввода, без TextMeshPro и без ассетов из Asset Store.
